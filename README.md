### ⭐ Featured — [DocWeave](https://docweave.tarunsumanthpuli.me/)

A Google-Docs-style editor where a whole team writes in the same document at once.

- **Real-time co-editing** — Yjs CRDTs relayed over Socket.IO, with live cursors, presence, in-doc chat and offline support
- **AI writing assistant** — ask, generate and rewrite, streamed token-by-token from Llama 3.3 70B via Groq
- **Access control** — Owner / Editor / Viewer roles from one permission resolver shared by the REST API and the socket layer
- **Versioning & export** — named snapshots with restore, server-owned autosave, export to PDF, DOCX, Markdown and HTML

`React 19` `Vite` `Tailwind CSS` `Tiptap` `Yjs` `Node.js` `Express` `Socket.IO` `MongoDB`
